# Dados

Esta pasta contém o conjunto de dados utilizado no projeto de modelagem preditiva da disciplina Estágio Supervisionado IV - Matemática Atuarial III.

## Conjunto de dados

**Health Insurance Data Set**

O conjunto de dados contém informações sobre segurados e características relacionadas ao risco em seguro saúde. O objetivo do projeto é utilizar essas informações para desenvolver uma modelagem preditiva do valor dos sinistros (`claim`).

## Fonte

Kaggle - Health Insurance Data Set

Arquivo original: `healthinsurance.csv`

## Observação

O arquivo original será preservado sem alterações. Eventuais procedimentos de limpeza, tratamento de valores ausentes e transformação das variáveis serão realizados posteriormente durante a etapa de preparação dos dados.
